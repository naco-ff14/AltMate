# 抽選記録・近距離追従の修正（v1.62.2）

応募確定ボタンで即保存していた処理を、10秒以内に応募価格と一致する所持ギル減少を確認してから保存する方式へ変更。失敗・残高不足・価格不明では記録しない。住所などはクリック時に保持し、看板が閉じても照合する。ログアウト・キャラ変更・期限切れで保留を破棄する。

これは支払いに基づく判定でサーバー成功通知の直接確認ではない。同額の別支出との区別、価格取得不能、10秒超の応答、確認前のログアウトによる記録漏れは残る。実ゲーム検証が必要。

抽選状態のキャラクターを右クリック →「このキャラクターの抽選記録をリセット」。応募先・抽選期限・結果確認・預かり金・応募住所IDのみ消去。キャラ情報、表示設定、所持金、ゲーム内応募は変更しない。

連携操作 →「後ろに回り込まず、近くまで寄る」。共通設定として保存・クライアント間同期。指定距離内ならその位置で待機し、範囲外なら最短方向へ接近する。通常追従はBMRを使わずAltMateが操作し、既存のvnavmesh復旧は利用する。戦闘・飛行の既存専用処理は変更しない。距離のキャラ・ペア別指定は引き続き有効。

検証：Releaseビルド、回帰テスト（失敗・残高不足・支払額一致、近距離停止・旋回・範囲外接近を追加）、diff確認。ゲーム内は未確認。
