# 空き土地の応募タイプ（v1.62.3）

確認日：2026-10-07。区・番地の隣に「購入対象」列を追加。FC / Solo / FC/Solo。本街・拡張街は同じ区分。既存の空き土地記録もWorldIdと区番号から表示時に判定し、再収集不要。

## 標準区分

日本DC（Elemental/Gaia/Mana/Meteor）、Aether/Primal/Crystal、7.0変更後のDynamis/Chaos/Light：
- 1–6、25区：FC
- 7–20、26–29区：FC/Solo
- 21–24、30区：Solo

Materiaは標準区分を適用しない。公式6.3表の1–9区FC、10–24区Soloに対応。25–30区は同告知で販売対象外であり、今回後続の販売区分を確認できなかったため「未確認」。未対応DC・無効な区・ワールド情報を取得できない場合も「未確認」。

公式の区分表による案内であり、現地のリアルタイム取得ではない。今後公式変更があれば対応表の更新が必要。

## 根拠

- 6.3 土地の追加と購入区分の変更：https://na.finalfantasyxiv.com/lodestone/topics/detail/f292e4bce622c2a01179339c676a7a36cb50c6a5
- 7.0 Dynamis / Phantom / Sagittarius / Alpha / Raidenの変更：https://jp.finalfantasyxiv.com/lodestone/topics/detail/c807875c5f8f7529887c86d2955f709eae0231ef

ビルド・回帰テスト成功。区境界・分類件数・Materia例外・未知区を検証。ゲーム内表示の目視確認は未実施。

表示幅：文字幅から列幅を計算。価格単位は見出しに集約、確認日時は短縮し狭い場合2段表示（完全日時はツールチップ）。応募記録数は「自キャラ」で全体人数との混同を防止。

住宅街列は24px（UI倍率対応）の都市紋章に置換。ミスト=リムサ、ラベンダー=グリダニア、ゴブレット=ウルダハ、シロガネ=クガネ、エンピレアム=イシュガルド。ゲーム内Townアイコン60881–60885を利用し、ホバーで住宅街名。未ロード時は「街」の文字とホバー名にフォールバック。Town対応は https://v2.xivapi.com/api/sheet/Town?fields=Name,Icon で確認。

「自キャラ」の人数へホバーすると同じ土地・現在周期の応募キャラクターを名前とワールドで表示。人数と名簿は同じ判定処理を利用。結果確認済みは注記し、応募なしはその旨を表示。

ログインごとに空き土地の初期ワールドをキャラクターのHomeWorldに設定。ログイン直後に情報未ロードなら描画時に取得を待つ。プラグイン再ロードにも対応し、選択後の手動変更は次のログインまで維持。ホームワールドに空き土地記録がなくてもALLに戻さず0件表示。訪問先ワールドではなくホームワールドを使用。
