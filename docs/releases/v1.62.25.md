# AltMate v1.62.25

## 通常制作の一次素材一覧

- 通常制作リストに「一次素材まで分解」を追加しました。
- 複数レシピから必要になる一次素材をアイテム単位で合算します。
- 中間素材は全キャラの所持数を差し引き、不足分だけを通常レシピで再帰展開します。
- 一次素材ごとに必要数、全キャラ所持数、不足数、保管場所を表示します。
- 一次素材一覧にも「不足のみ」を追加しました。

## クリスタル類の非表示

- 各属性のシャード、クリスタル、クラスターを通常素材一覧、FC制作素材一覧、一次素材一覧から非表示にしました。
- 中間素材の内訳でもクリスタル類を表示しません。

## 一次素材計算の修正

- レシピから直接要求される一次素材の在庫を二重に差し引く問題を修正しました。
- 通常制作とFC制作の両方に同じ計算方法を適用しました。
