# AltMate v1.62.23

## 保管場所表示の整理

- 素材の保管場所をキャラクター／FC単位のブロックにまとめました。
- 所有者名の繰り返しを減らし、その下に所持品、チョコボかばん、リテイナー、FCチェストなどを改行して表示します。
- キャラクター／FCごとの合計所持数を表示します。
- HQとNQは保管先ごとに分けて表示します。
- 通常レシピ、FC制作、一次素材、全アイテム一覧で同じ表示形式を使用します。

## クリスタル類の別枠表示

- 各属性のシャード、クリスタル、クラスターを通常素材から分離しました。
- 通常レシピ、FC制作の納品素材、一次素材まで分解した一覧で、紫色の専用見出しと別テーブルに表示します。
- クリスタル類も必要数、所持数、不足数、保管場所を個別に確認できます。
