# AltMate v1.62.20

## FC製作・潜水艦パーツ素材計画

- 潜水艦・飛空艇パーツ、ハウス外装などを複数選択し、一つの作成リストで管理できるようにしました。
- 各製作物の数量を指定し、全工程の納品素材をまとめて合算します。
- 納品素材を中間素材、フレーム、一次素材、クリスタル類に分類します。
- 全キャラクターの所持品、チョコボかばん、アーマリーチェスト、リテイナー、FCチェスト、愛蔵品、ミラージュドレッサーの保存済み在庫を自動で差し引きます。
- 不足している中間素材を通常レシピで再帰展開し、必要な一次素材まで一覧化します。
- 中間素材を選択すると、その素材を作るための直接素材の内訳を確認できます。
- 各素材の必要数、所持数、不足数、キャラクター／FC別の保管場所を表示します。

参照した素材計算シートの手入力在庫欄は増設せず、AltMateの全キャラアイテムDBへ統合しています。
