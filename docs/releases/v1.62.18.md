# AltMate v1.62.18

## レシピ素材の確認を改善

- 作りたいレシピと製作回数を選ぶと、直接素材ごとに必要数、全キャラ所持数、不足数、保管場所を一覧表示します。
- 不足している素材の種類数を上部に表示します。
- 「不足のみ」で、足りない素材だけに絞り込めます。
- 選択したレシピを画面上から選び直せます。

## 全アイテム一覧

- 保存済みの全アイテムを確認できる独立ウィンドウを追加しました。
- アイテム名・アイテムID、キャラクター／FC、保管先で絞り込めます。
- アイテムごとの合計数、キャラクター、具体的な保管場所、最終確認日時を表示します。
- 大量のアイテムも確認しやすいよう、200種類単位でページ表示します。

## アーマリーチェスト

- 武器、防具、アクセサリー、ソウルクリスタルをキャラクター別に保存します。
- レシピ素材の保管場所と全アイテム一覧の両方へ反映します。
