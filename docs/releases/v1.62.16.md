## プラグインのコードをWebで承認して連携

- `/altmate → 設定 → Webダッシュボード同期 → Webと連携する（コード発行）` で12文字のコードを表示します。
- 「コードをコピー」→「Webでログイン・連携」を押し、Webにメールアドレス・パスワード・コードを入力すると、ログインと連携を一度に行えます。コードは初回のみの任意入力です。
- ログイン済みの場合は、Webの「設定 → プラグイン連携」でコードを登録します。「同期端末」の独立メニューは「設定」にまとめました。
- Webで承認されると、連携を開始したDalamudインストールの同期を自動でONにします。別アプリのSync Agentは起動不要です。既存の連携は再登録せずに引き継げます。
- コードは10分間有効で、1回だけ承認できます。認証情報を受け取るための別の秘密情報はプラグイン側だけに保持し、Windowsユーザー向けに暗号化して保存します。パスワードをプラグインへ入力する必要はありません。

## サーバー更新

既存環境はdashboard-v2の後に [plugin-pairing.sql](https://github.com/naco-ff14/AltMate/blob/v1.62.16/supabase/migrations/202610290003_plugin_pairing.sql) をSQL Editorで一度実行し、既存の `sync` Edge Functionを更新してください。初期SQLの再実行や既存PC登録の削除は不要です。Verify JWT with legacy secretはOFFのままにします。

[詳しい設定手順](https://github.com/naco-ff14/AltMate/blob/v1.62.16/docs/plugin-web-sync-ja.txt)
