# AltMate v1.62.24

## 2クライアント間の在庫同期修正

- SQLiteの読込中にローカル在庫が更新された場合、古い読込結果で新しいメモリキャッシュを上書きしないようにしました。
- 読込中に在庫世代が変化した場合は結果を破棄し、安定した状態で再度読み込みます。
- Aキャラの更新内容がBキャラへ反映された後、古い表示へ戻るような交互更新を防止します。

## FCチェストの上書き防止

- FCチェスト画面を実際に開いているクライアントだけを、FC在庫の更新元として扱います。
- ゲーム内部に残った読込済みコンテナを、チェストを閉じたキャラクターが再保存しないようにしました。
- 同じFCの複数キャラクターが起動している場合に、古いチェスト内容で現在の内容を上書きする問題を防止します。
