# AltMate v1.62.21

## 制作リストとアイテム操作

- 通常レシピを複数選択し、一つの制作リストで管理できるようにしました。
- 複数レシピで共通する素材は合算して表示します。
- 同じレシピの再追加、制作回数の変更、個別削除、全消去に対応しました。
- 通常レシピ、FC制作、素材内訳、直接検索、全アイテム一覧で、アイテム名をクリックするとクリップボードへコピーします。

## アイテムDBの高速化

- 全件書き換え式のJSONから、複数クライアント対応のSQLite WALデータベースへ移行しました。
- 既存の`item-inventory-v1.json`は初回起動時に自動移行し、移行済みファイルをバックアップとして残します。
- DB保存をゲームスレッドから分離し、連続した変更をバックグラウンドで一括保存します。
- 変更されていない保管先の書き込みを省略し、Item ID検索用のメモリ索引を追加しました。
- アイテム変化を短時間でまとめて再スキャンし、在庫リビジョンの変化を素材一覧・直接検索・全アイテム一覧へ反映します。
- 通常制作とFC制作の素材集計は、制作リストまたは在庫が変化した場合だけ再計算します。
