# AltMate v1.62.17

## 全キャラ アイテム管理

- 所持品、チョコボかばん、リテイナー、FCチェスト、愛蔵品、ミラージュドレッサーを横断検索できる「アイテム管理」を追加しました。
- 作りたいアイテムと製作回数を指定すると、直接素材の必要数、全キャラ所持数、不足数、具体的な保管場所を表示します。
- アイテム名またはアイテムIDから直接検索できます。
- リテイナー在庫は所有キャラクター名とリテイナー名を組み合わせて表示します。
- FCチェスト在庫はFC ID単位で保存し、同じFCに所属する複数キャラクターによる重複計上を防ぎます。
- 最終確認から7日以上経過した情報は警告色で表示します。

## 在庫情報の更新

- 所持品とチョコボかばんはログイン中に自動更新されます。
- リテイナー、FCチェスト、愛蔵品、ミラージュドレッサーは、ゲーム内で各画面を開いてデータを読み込むと更新されます。
- 複数のFF14クライアントから同時に更新できるよう、共通データ領域とプロセス間ロックを使用します。
