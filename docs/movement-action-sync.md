# ジャンプ・スプリント連携

「連携操作」の自動追従設定の下に、次の共通設定を追加しています。初期値は両方OFFです。

- リーダーのジャンプに合わせてジャンプ
- リーダーのスプリントに合わせてスプリント

リーダーとフォロワーで連携を有効にすると、選択中のリーダーの操作を同じワールド・エリアのフォロワーへ個別に送ります。自動追従の距離や更新間隔を待たず、受信したフレームで一度だけ実行します。厳密な同時実行ではなく、通信とフォロワーのフレーム更新分の遅延があります。自動追従自体のON/OFFとは独立しています。

一般アクションのジャンプとスプリント、および通常アクションのスプリントを、既存のアクション監視で受け付けられた後に検出します。ジャンプはキーボード・コントローラー入力を補うため、ジャンプ状態が始まってから150ms以内の上昇もフレームごとに監視します。単なる落下、ログイン時やエリア変更後に既に空中にいる状態では送信しません。

重複通知は受信シーケンスと送信側250msの抑制で除外します。750msを超えた通知は破棄し、詠唱中・緊急停止中・移動やイベントの処理中などは予約せず見送ります。相乗り中は実行しません。ジャンプは既にジャンプ・落下中なら見送り、マウント状態がリーダーと一致する場合にのみ実行します。スプリントはマウント中・既に効果中・再使用待ち・アニメーションロック中なら見送ります。BMR・RSR等の設定や操作権は変更しません。

## 確認範囲

回帰テストでアクション識別、30/60fps相当のジャンプ検出、落下の除外、重複抑制、停止・リーダー変更・別ワールド・別エリアでの拒否、通知期限、共有設定の競合マージを確認します。

ゲーム内での入力経路、実際の遅延、マウント離陸・上昇、BMR/RSRとの同時使用は実機確認が必要です。
