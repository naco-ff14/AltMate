AltMate プラグイン内Web同期（開発ブランチ版）

設定場所
  /altmate → 設定 → Webダッシュボード同期

すでにPC同期アプリを使っている場合
  1. 2-start-sync.cmd で開いていた同期ウィンドウを閉じてください。
  2. プラグインの設定で「Web同期を有効にする（このクライアント）」をONにします。
  既存のPC連携・暗号化された送信待ちデータはそのまま使います。
  同じWindowsユーザーであれば、コードを発行し直す必要はありません。
  この設定はそのDalamudインストールのローカル設定として保存します。
  他のクライアントの同意を自動でONにはしません。

初めて連携する場合
  同期をOFFにした状態で、SupabaseのProject URLと、Webの「同期端末」で発行した
  連携コードを入力して「このPCを連携」を押してください。
  連携後に同期をONにします。パスワードや管理用APIキーは不要です。

同期中の操作
  「今すぐ同期」、最終送信時刻、次の確認時刻、送信待ち状態を表示します。
  サーバーの5分間隔の制限は、手動同期でも守ります。
  制限に当たった場合はサーバー障害と区別して表示します。
  ゲームを操作するメインスレッドでは、ファイル読み出しや通信を行いません。
  同期OFFとプラグイン終了は、通信を中止し、送信待ちデータを残します。
  終了時にネットワークの完了待ちでゲームを止めません。
  実行中の通信中止時は、サーバーにすでに届いている場合もあります。
  その場合も同じ送信番号で再試行して二重取り込みを防ぎます。

複数クライアント
  同じPCでは1つのクライアントのみが送信を担当します。
  ほかの有効なクライアントは待機し、担当が終了したら引き継ぎます。
  外部Sync Agentが起動している場合も競合せず待機します。

連携を解除する場合
  同期をOFF →「PC側の連携情報を削除…」で確認して削除します。
  PC上の認証情報と送信待ちデータだけを削除します。
  Webの端末登録は残るので、Web側の「同期端末」で無効にしてください。

開発版の導入
  これは feature/web-dashboard ブランチのテスト用ビルドです。
  mainの公開リリースは変更していません。
  Dalamudの開発プラグインとして、展開したフォルダーの AltMate.dll を指定して使えます。
  通常版と開発版のAltMateを同時に有効にしないでください。
  既存の設定やPC連携ファイルを削除する必要はありません。

検証範囲
  プラグインのReleaseビルド、既存の回帰テスト、同期エンジンとプラグイン用ワーカーの
  自動テストを実行しています。送信OFF・排他・再試行・中止・暗号化・同意の非伝播を確認します。
  開発版を実際にゲームへ読み込んだ際の画面・プラグインからの実送信は未検証です。
  同期元の観測内容は、既存のAltMateが保存した記録に依存します。
