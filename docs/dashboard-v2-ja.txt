Webダッシュボード 表示・同期データの改善

概要
  総資産と、ハウジング・潜水艦・お得意様の確認が必要な件数だけを表示します。
  明細はそれぞれの専用画面へ分けます。

ハウジング
  土地抽選、ハウス保持期限、空き土地の3つに分けます。
  抽選は応募済み、応募記録なし、今期未確認、結果未確認、結果確認済みを区別します。
  抽選周期は同期したプラグイン設定から算出し、未同期時は既存の応募期間終了から推定します。
  推定もできない場合は、周期未確認として扱います。
  保持期限は最終入室+45日の推定。同じFCハウスの記録はまとめて、全メンバーの最新入室を使います。
  空き土地は、ワールド・地区・区・番地・サイズ・価格・観測日時で確認できます。
  撤去停止期間、未同期の入室、土地の成約などはWebだけでは判定できません。

ギル
  個人資産（所持金+リテイナー）、FC資金、今期の未確認の抽選預かり金、総資産を表示します。
  キャラごとの所持金/リテイナー/個人資産/抽選預かりと、FCごとの資金を一覧にします。
  所持金・個人資産の昇順/降順と名前順に切り替えられます。
  未記録や未確認の残高は0と扱わず、集計が一部の記録に基づくことを明記します。

潜水艦
  FCごとに、未出航・待機、帰港予定経過、航海中、未確認を表示します。
  未出航・帰港予定経過のあるFCだけに絞れます。
  帰港予定経過は実際の回収や再出航を確認した意味ではありません。

お得意様
  全登録キャラに対して、未消化、消化済み、今週未確認、記録なしを表示します。
  クラフター/ギャザラーそれぞれの紫貨・橙貨と最終観測日時を表示します。
  火曜08:00 UTC（日本時間17時）の週切り替わり後、古い記録は今週未確認になります。
  実際の残り回数を未同期のまま12回に置き換えることはしません。

時間の扱い
  表示中は30秒ごとに残り時間と状態を再計算し、画面に戻った時も即時更新します。
  ゲームやSync Agentが停止していても、Web側の残り時間は進みます。
  元の観測データが変わるのは、ゲーム側で観測して再同期したときです。

追加同期データの有効化（すでに同期が動いている利用者向け）
  1. 同梱 dashboard-v2.sql をSupabase SQL Editorで実行。
     既存の認証・RLS・保存データは維持します。
  2. 既存のEdge Function sync のコードを同梱 sync-function.ts の全文で更新。
     関数名とJWT設定は現在と同じ。管理キーをPCにコピーする必要はありません。
  3. 追加データ対応版のプラグインまたはSync Agentから同期。
     現在の公開版v1.62.14にはリテイナーや空き土地の送信がないため、この更新が必要です。
  既存のPC連携は引き継ぎます。元の supabase-sync.sql は実行し直さないでください。

Web画面はv1.62.14の既存データでも動作します。不足項目は未同期として表示します。
追加データを推測で埋めたり、未観測の残高や状態を確定扱いすることはありません。

検証
  総資産、未確認値、抽選周期、週の切り替わり、FCハウス集約、PC別の一覧情報、
  サーバーの追加データ許可・古い値の保護、ブラウザの絞り込み/並べ替え/時間進行を検証します。
  実ゲームから追加データを送信しての最終表示は、サーバー更新と対応版導入後の確認が必要です。
