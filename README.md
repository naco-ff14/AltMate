# AltMate

[Discordサーバーに参加する](https://discord.gg/gPu6reUhDw)

同じPCで起動している複数のFFXIVキャラクターをまとめて支援するDalamudプラグインです。
追従・移動・戦闘などの連携操作に加え、ハウジング抽選、ギル、FC潜水艦の情報をキャラクター横断で管理できます。

日本語／英語UIに対応しています。

## 主な機能

### Webダッシュボード同期（開発ブランチ）

- 設定 →「Webダッシュボード同期」から、プラグイン内でPC連携・送信ON/OFF・手動同期
- 初期値OFF。既存のWindows Sync AgentのPC連携情報と暗号化キューを引き継ぎ
- 5分間隔のバックグラウンド送信、最終送信・待機・エラー表示
- 複数クライアントと外部Sync Agentの間で送信担当を1つに制限
- 終了・OFF時に通信を中止し、未送信データを保持

導入と検証範囲は [プラグイン内同期の説明](docs/plugin-web-sync-ja.txt) を参照してください。

### 連携操作

- リーダーとフォロワーを指定し、同じPC上の複数クライアントを連携
- リーダーの後方を目標にした滑らかな自動追従
- リーダーのジャンプ・スプリントへの即時連携（個別設定、初期値OFF。使用できない場合は見送り）
- A–B間の追従距離、Dead Zone、Catch Upを考慮した移動
- 相乗り要求と、相乗りできない場合のマウントルーレットへのフォールバック
- リーダーがマウントを降りた際のフォロワー降車
- パーティ招待、テレポ招待、コンテンツ突入確認の自動承認
- リーダーが操作したNPC／オブジェクトの連携
- 戦闘中はAltMateの移動を停止し、BossMod Reborn／Rotation Solver Rebornへ制御を移行
- リーダー／フォロワー別のFPS上限
- 連携操作の一時停止と再開

### 移動連携

- 通常テレポ
- 都市内／住宅地のエーテライト移動
- クレセントアイル内エーテライト移動
- デジョン
- エリア境界の徒歩移動
- FCハウスへの移動と、出入りの確認ダイアログ連携

移動連携の一部にはLifestreamが必要です。

### アニメーション

画面内を次の2タブに分けて表示します。

- **ゲーム内エモート**: 取得済みのエモートを検索し、選択したキャラクターで再生
- **Penumbra**: 現在有効なPenumbra差し替えエモートを一覧化し、選択したキャラクターで再生

### ハウジング

- キャラクターごとの抽選応募先、応募期間、結果確認状況を管理
- 現在の抽選サイクルと締切を表示
- 確認した空き土地をワールド、区、番地、サイズ、価格とともに保存
- 応募先を右クリックしてLifestreamで移動
- 結果発表期間に未確認の応募先へコマンドから移動
- 表示対象キャラクターを個別に設定
- 「表示キャラクター」からキャラ単位で抽選記録をリセット（対象と資産計上への影響を確認して実行）

### ギル管理

- キャラクター、リテイナー、FCチェストの所持ギルを集計
- ハウジング抽選に預けているギルを別表示
- 0ギルのリテイナーを省略
- リストヘッダーのクリックでキャラクター名、ワールド、所持ギルを並び替え
- FC名と所属ワールドを表示

### 潜水艦管理

- FC単位で潜水艦名、航行状態、帰還予定、残り時間を表示
- 右クリックメニューで航行航路を表示
- カンパニーワークショップの潜水艦管理画面を開いた際に情報を自動更新
- 帰還結果から財宝アイテムのNPC換金額を記録
- FC単位で「トータル」「選択月」「1航行当たりの平均」「換金効率（G/日）」を集計

潜水艦の換金額は、AltMate導入後にゲーム内で確認できた帰還結果から蓄積されます。

### ウィンドウと共有設定

- 前回開いていたメニューと通常／最小化表示を次回起動時に復元
- 別のDalamud環境で起動したAltMate同士がローカル設定と収集データを共有
- 連携先の状態をリーダー側から確認

## インストール

Dalamud設定の「カスタムプラグインリポジトリ」に次のURLを追加します。

```text
https://raw.githubusercontent.com/naco-ff14/AltMate/main/repo.json
```

## コマンド

基本コマンドは `/altmate` です。引数なしの場合は前回の表示状態で開きます。

| コマンド | 動作 |
|---|---|
| `/altmate` または `/altmate open` | 前回の表示状態で開く |
| `/altmate min` | 最小化状態で開く |
| `/altmate max` | 最大化状態で開く |
| `/altmate stop` | 連携操作を停止 |
| `/altmate resume` | 連携操作を再開 |
| `/altmate animation` | アニメーション画面を開く |
| `/altmate housing` | ハウジング画面を開く |
| `/altmate gil` | ギル管理画面を開く |
| `/altmate submarine` | 潜水艦管理画面を開く |
| `/altmate lottery` | 結果発表期間に未確認の応募先へ移動 |

## 連携プラグイン

| プラグイン | 用途 | 必須 |
|---|---|---|
| Lifestream | テレポ、エーテライト、住宅地、応募先への移動 | 対象機能のみ必要 |
| Penumbra | 差し替えエモートの検出と再生 | 対象機能のみ必要 |
| BossMod Reborn | フォロワーの戦闘移動制御 | 任意 |
| Rotation Solver Reborn | フォロワーの戦闘行動制御 | 任意 |

## データとプライバシー

共有データは同じPC内の次のファイルへ保存されます。

```text
%LOCALAPPDATA%\AltMate\shared-config.json
```

キャラクター情報、ハウジング情報、ギル情報、潜水艦情報、連携設定は外部サービスへ送信しません。AltMateのチャット通知はローカル表示で、他プレイヤーには送信されません。

## ビルド

- Dalamud API 15
- .NET 10

```shell
dotnet build -c Release
```

### カンパニークレジットの回帰テスト

ゲームを起動せずに、パーサー・観測状態・実際の共有設定ファイルのマージを検証できます。

```shell
dotnet run --project tests/Regression/Regression.csproj -c Release
```

- カンマ、ピリオド、空白、NBSP、narrow NBSP の桁区切り、0・少額・ランクと同程度の残高、uint 上限を検証
- 負数・オーバーフロー・不正な文字列を拒否し、更新イベントなしのポーリングでは確定しないことを検証
- 非0 → 0 → 非0、未取得、キャラクター・FC・エリア・アドオン・プロキシの切り替え、画面を閉じる／ログアウト時のリセットを検証
- 同じ表示元で中間値の更新イベントを観測した場合は、次のポーリング前に元の残高へ戻っても確定できることを検証（リセット後は中間値の証拠を引き継がない）
- 元のイベント時刻を保持し、変化のないローカル表示や古い保留サンプルが新しい共有残高を上書きしないことを検証（再オープン時を含む）
- 一時ディレクトリ内の2つの共有ストアで、確定済み0の保存・再読込と、FCチェストのギル・潜水艦・航行履歴の独立した保持を検証

これらは純粋な観測ロジックとファイルマージの回帰テストです。ゲーム内のネイティブデータが取得済みであることや、UIの値が正しいフィールドから読み取られたことは証明しません。実機ではFC画面の読み込み中・再オープン・残高変化・キャラクター切り替えも確認してください。

既知の制限も回帰テストで明示しています。同じ表示元で100を観測した後、別クライアントまたは別画面が200を共有し、元の表示元が200を観測しないまま実際の残高が100に戻った場合、古い表示との区別ができず100への更新を抑制します。再オープンでも同様です。このテストの成功は制限の解消を意味しません。クレジット専用の新鮮なデータを識別できるネイティブイベント／応答の検証が必要です。

初期表示の仮の0と取得済みの0を完全に区別できることも未確認です。更新・実機検証前に全AltMateインスタンスを停止し、共有設定とDalamud側のAltMate設定を別の場所にバックアップしてください。[v1.62.13のリリースノート](docs/releases/v1.62.13.md)と[実機検証手順](docs/fc-credit-capture.md)に制限と詳細を記載しています。
